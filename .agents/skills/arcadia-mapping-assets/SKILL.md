# Arcadia mapping, assets, and visuals

Read `.github/guides/MAPS_AND_AWAY_MISSIONS.md`, `.github/guides/VISUALS.md`, relevant map/module README files, and the map/icon tooling being used.

## Maps

- Preserve TGM format. Prefer StrongDMM/FastDMM2 and repository map-merger hooks; do not use Dream Maker's map editor.
- Identify every map/config/loader/code consumer before adding or moving content.
- Use `tools/UpdatePaths` for mass type-path changes affecting maps. Do not regex-replace DMM keys.
- Keep station-map JSON, ruin/shuttle metadata, modular-map TOML, blacklists/rotation, and map-specific DM consistent.
- Do not hand-edit generated `_maps/templates.dm`; use the build target.
- Validate changed maps with mapmerge/TGM checks, maplint, compilation, and relevant integration tests.

## Icons and visual state

- Determine whether DMI/PNG output is generated by icon cutter; edit its source/config when generated.
- Preserve icon states, directions, frame counts, delays, dimensions, and metadata expected by DM and maps.
- Prefer appearances for overlays/underlays and cache reusable appearances; avoid repeated raw icon conversion.
- Use the repository overlay/update helpers. Respect plane, layer, render target/source, mouse opacity, lighting, and multiz behavior.
- Add or update screenshot tests for meaningful rendered-output contracts and review the actual diff image.

## Rights and review

Verify provenance and compatible licensing for every added/modified asset; record required artist/codebase attribution. Do not generate or import replacement art without confirmed rights and explicit task scope. Avoid touching unrelated map keys or DMI states because both create costly merge conflicts.
